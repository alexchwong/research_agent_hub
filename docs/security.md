# Security and data handling

The CLI binds the hub to 127.0.0.1. A private instance record lets the launcher challenge the service and pass a hub-session access token to the browser. API mutation requests require an exact Host, Origin and bearer token. The HTML shell has no private data. The tab stores the bearer in sessionStorage when available and immediately removes the launcher fragment. Reload restores the tab within the running hub. Navigation URLs contain only project and chat IDs. Authentication failure and Quit clear the bearer. After a restart, open the launcher and restore saved chats from the sidebar. A hostile process already running as the same OS user or an administrator is outside the application boundary.

Protect native launch directories and local data as well as the hub configuration. Per-app settings are projected through an allowlist. Keep RAH's environment file outside all native source roots. User-owned native app settings remain separate. Upload contents are local and downloaded as attachments.

Private PDF approval binds the originating project and request, ordered file IDs/names/hashes, question, explicit excerpt, effective key, compatible install and reviewed provider/lock identity. Declining or revisiting a chat starts no worker. Native entry points remain available for user-controlled use. See [release evidence](releases.md) for the reviewed profile and platform status.

GPT Researcher’s Classic UI runs on its own loopback origin. The deployment wrapper validates Host, requires its native Origin for WebSocket and HTTP mutations, rejects foreign browser subresources, and disables forwarded proxy headers. Its readiness route checks a per-launch token. Standalone use is local and retains the upstream browser and native credential choices.

Classic native draft handoffs transfer only the question over loopback and use a short-lived, single-use ticket. The fragment contains the ticket, not the draft, and is cleared when the destination tab reads it. Prefill does not submit the native form. Classic LDR result saves use its authenticated native export in the destination tab and a workspace-scoped local grant; RAH does not import LDR credentials, session cookies or database records. Guided stages have no native handoff and no export grant.

The PaperQA2 worker receives only the scoped OpenRouter credential for the approved route. Each managed route uses one approved provider per role and disables provider fallbacks; the worker refuses any other URL, model, provider, model list or redirect. Routes stay disabled until their P6 evidence is added for a platform. A response that omits its serving provider is recorded as unobserved.

## Guided research data flows and approvals

| Flow | What is sent | Approval |
| --- | --- | --- |
| Survey | The exact public question to GPT Researcher, which sends it to OpenRouter (provider selected by the service) and the configured search service, may fetch public pages from results and loads tokenizer data on first use. No chat files, paths, earlier turns or project names. | One click on **Start public research** below a disclosure built from the effective route. The server re-derives the display digest and both fingerprints before creating the run. Re-confirmation only on a material route change, never on elapsed time or restart. |
| Scope Gate | The public question and up to 12,000 characters of the run's own survey (frontmatter and link targets removed). Round 2 adds the displayed questions and submitted public answers (at most 4,000 characters). | Covered by the public start review, which discloses the model and its limitation. |
| Downstream public stages | The exact approved prompt to GPT Researcher, or to headless LDR (`quick_summary`), which sends it to its model endpoint, its search API, the fixed hosts listed in the approval (OpenAlex enrichment and journal-quality reference data) and may fetch public pages from any host. | Scope approval of the exact prompt and recipient fingerprints. A material route change (install, lock, models, search, credentials, prompt, runner/observer) requires re-confirmation naming the dimension. |
| Open-access lookups | Only canonical public DOIs or PMCIDs, plus the tool name and maintainer contact for DOI conversion. Never titles, notes, report text, PDF metadata or files. | Automatic only when the opt-in setting is on and the identifier came unchanged from a confirmed public result. Private or unknown identifiers: one action per batch of up to 20, each paper bound to an immutable grant (origin, identifiers, version, sequence, endpoints, contact) checked at admission and before every request; a DOI's Cloud Service follow-up is allowed only for the PMCID the converter returned for that DOI. Any change skips the paper with `changed_after_approval`. |
| PaperQA2 | Extracted text, the private question, any excerpt and citation details from the exact selected PDFs. | One **Send N PDFs** click per run, enabled only after a read-only `pqa-preflight` returns the exact disclosure and `disclosure_digest` (files, question, excerpt, quality, route, destinations, credential HMAC, worker and observer). The bound preview must reproduce the digest before approval, and `run_paper` re-verifies the binding. |

Route fingerprints include a keyed HMAC of each relevant credential (key stored in the private hub config, separate from the tab bearer) and never the value. Guided API mutations require the local bearer, exact Host and Origin, UUID identifiers and known fields only; they accept no paths, endpoints or routing settings. Request and action IDs are recorded with payload digests so a double click or replay cannot dispatch twice. Classic entries cannot be used to bypass guided approvals.

Guided GPT Researcher runs use a private working directory, empty `DOC_PATH`, private home directories, `PYTHONNOUSERSITE=1`, `PYTHON_DOTENV_DISABLED=1`, image generation off and MCP disabled. Raw stdout and stderr are counted and classified in memory only; native outputs are saved only through the artifact registry. Acquisition dials validated public addresses directly, keeps the original hostname for TLS SNI, certificate checks and `Host`, refuses redirects and unexpected encodings, bounds metadata to 256 KiB and PDFs to 256 MiB, and stops automatic downloads at 40 files or 512 MiB per run. Reports render as plain text with safe links; RAH never loads report-supplied images or HTML.

The usage observer writes only numeric usage, model, provider, generation ID, status and a reason to `usage.jsonl` in the attempt folder; RAH stores the per-entry summary in `chat_entry.usage_json` (at most 8 KiB). `pqa-preflight` is a POST under the same mutation protections because its body carries the private question, and it writes nothing.
